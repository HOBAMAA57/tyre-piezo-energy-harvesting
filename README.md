# Tyre Piezoelectric Energy Harvesting System

## 📌 Project Overview

This project is a prototype system that converts mechanical pressure generated by tyre movement into electrical energy using piezoelectric sensors.

The generated energy is stored and used to power an LED. A TFT display is included to monitor the system output.

## ⚙️ Components

- Arduino
- Piezoelectric Sensors
- TFT Display
- Capacitor
- LED
- Resistors
- Tyre Setup

## 🔧 Working Principle

1. Mechanical pressure is applied to the tyre.
2. Piezoelectric sensors generate electrical energy.
3. The generated energy is stored in a capacitor.
4. The TFT display shows the system readings.
5. The stored energy is used to power an LED.
